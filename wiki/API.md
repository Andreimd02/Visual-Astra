# API e Módulos

## src/BuildFunctions.py
Funções para construção de atores (cubos, discos) e trajetórias (reta, círculo).

## src/interactor2d.py
Classe `CustomInteractor` para manipulação de eventos de interação 2D.

## src/AstraCustom.py
Customizações e integrações específicas do Astra.

## src/settings.py
Configurações de cores e parâmetros globais do simulador.

## src/view/
Interface gráfica, diálogos e janela de simulação.
