# Desenvolvimento

## Como contribuir
1. Faça um fork do repositório
2. Crie uma branch para sua feature ou correção
3. Envie um pull request

## Convenções de Código
- Siga o padrão PEP8 para Python
- Documente funções e classes usando PEP257
- Utilize comentários explicativos em partes complexas

## Testes
- Adicione testes unitários para novas funcionalidades
- Testes podem ser adicionados na pasta `src/view/teste.py`
