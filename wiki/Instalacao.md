# Instalação

## Requisitos
- Python 3.8+
- matplotlib
- numpy
- vtk
- PyQt5
- scipy
- scikit-image
- wheel

## Passos para Instalar
1. Clone o repositório:
   ```powershell
   git clone https://github.com/Andreimd02/Visual-Astra.git
   ```
2. Instale as dependências:
   ```powershell
   pip install -r requirements.txt
   ```
3. Execute o simulador:
   ```powershell
   python main.py
   ```
