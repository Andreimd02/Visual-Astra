# Guia de Uso

## Executando o Simulador
Após instalar as dependências, execute:
```powershell
python main.py
```

## Funcionalidades Principais
- Visualização 3D de objetos, fontes e detectores
- Simulação de trajetórias (reta e circular)
- Customização de cores e posições
- Manipulação interativa dos elementos

## Exemplos de Uso
- Para alterar parâmetros de simulação, edite os arquivos em `src/settings.py`.
- Para adicionar novos tipos de trajetórias, utilize as funções em `src/BuildFunctions.py`.
